## Core Expertise

### WordPress Plugin Engineering
Custom plugins built from scratch with clean architecture, PSR-4 autoloading, Composer dependency management, and full WordPress Coding Standards compliance.

- Custom post types, taxonomies, and meta APIs
- `WP_Query`, `$wpdb`, and database optimization
- Hooks, filters, and action scheduler workflows
- Nonces, capability checks, sanitization, and escaping
- PHPUnit testing and GitHub Actions CI pipelines
- CSV, JSON, XML, and REST API data pipelines

### WooCommerce Development
Custom WooCommerce extensions and integrations for real-world e-commerce needs.

- Custom product import/export — CSV and JSON
- Payment gateway and shipping method integrations
- Order automation and custom workflows
- WooCommerce REST API and webhooks
- Subscriptions, memberships, and bookings

### Gutenberg Block Development
Modern block development using React, `@wordpress/scripts`, and the WordPress Interactivity API.

- Custom dynamic and static blocks
- Block variations and block patterns
- Full Site Editing (FSE) and block themes
- `theme.json` based theming
- Block bindings for dynamic data

### Headless WordPress
WordPress as a backend-only CMS with modern JavaScript frontends.

- REST API and GraphQL integration
- React and Next.js frontends
- JWT authentication
- Custom REST endpoints

### WordPress Theme Development
Both classic PHP themes and modern block-based themes.

- Classic themes with custom template hierarchy
- Block themes with `theme.json`
- Custom Gutenberg-ready themes
