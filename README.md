## About

I am a WordPress developer with 5 years of professional experience building custom themes, plugins and Gutenberg blocks for client and agency projects. My work covers the full WordPress stack: PHP on the server, React in the block editor, and the REST API in between.

My current focus is WordPress plugin engineering: object-oriented PHP with Composer and PSR-4 autoloading, WordPress Coding Standards enforced with PHPCS, automated testing with PHPUnit, and CI with GitHub Actions.

## Currently working on

**Relay Core** — a WordPress CSV importer plugin that turns any CSV file into custom post type entries.

- Namespaced, PSR-4 autoloaded PHP with single-responsibility classes (file validation, CSV reading, row validation, import)
- WordPress Coding Standards enforced with PHPCS and PHPCBF
- Local development with `wp-env` and Docker on WSL2
- Next: PHPUnit test suite, GitHub Actions CI, background processing with Action Scheduler

**Up next** — Relay for WooCommerce: product, stock and price sync for large catalogs, built on the WooCommerce CRUD layer with HPOS compatibility.
